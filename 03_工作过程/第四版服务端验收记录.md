- URL 协议、凭据、DNS 与公网 IP 校验，作为 SSRF 第一层防护。
- Dockerfile、环境变量样例和本地运行说明。

## 已修复问题

初次服务端测试发现 SQLite 连接使用上下文管理器时只处理事务，没有显式关闭底层连接，Windows 因文件仍被占用而无法清理临时数据库。现已统一使用 `contextlib.closing` 并在写操作后显式提交，资源警告和文件占用均消失。

## 剩余风险

- 应在 Linux 容器环境验证真实 yt-dlp 下载、FFmpeg 合并和进程取消。
- DNS 校验不能单独彻底解决 DNS rebinding；生产部署必须增加网络出口防火墙规则。
- 当前是单机 SQLite + 进程内线程池，适合首个里程碑，不适合多实例横向扩容。
- API Key 是单密钥模式；后续若增加多用户，需要改为用户级令牌和权限模型。
