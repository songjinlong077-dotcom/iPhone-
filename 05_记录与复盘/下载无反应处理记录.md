# “开始下载无反应”处理记录

- 日期：2026-10-05
- 用户现象：点击“开始下载”后不能正常下载视频。

## 复现与验证

桌面快捷方式、Python 环境和默认保存目录均存在。新增完整 GUI 集成测试，直接调用真实“开始下载”按钮，经过本地 HTTP 服务下载 MP4 并校验落盘内容，流程通过。

## 改进

- 点击按钮后立即显示“正在检查 URL 和保存位置”。
- 输入、保存路径和意外校验异常全部在状态栏及中文对话框显示。
- 已有任务运行时不再静默返回。
- 下载按钮运行期间显示“下载中…”。
- 界面明确提示第一版仅支持视频文件直链，不支持普通视频网站页面。
- 修复 GUI 销毁时残留的定时回调警告。

## 当前判断

程序对 MP4 直链的按钮流程正常。若用户使用普通网页地址、受登录/防盗链保护的地址或已失效链接，更新后的界面会显示具体错误，需要结合实际 URL 继续判断。
