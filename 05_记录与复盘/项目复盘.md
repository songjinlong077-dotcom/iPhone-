# Project002 第一版复盘

- 日期：2026-10-05
- 状态：完成

## 验收结论

第一版实现了中文 GUI、MP4 直链流式下载、进度/大小/速度展示、后台线程、打开文件夹，以及无代理、HTTP、HTTPS、SOCKS5 和可选认证。14 项自动化测试、有效 MP4 直连与 HTTP 代理集成验证、SOCKS5 转发测试、真实下载按钮流程、GUI 启动和依赖检查全部通过。

## 关键决策

- Tkinter 是 Python 自带 Windows GUI，减少部署依赖。
- Requests 负责成熟的 HTTP 流式传输，PySocks 提供 SOCKS5 支持。
- Tk 主线程只处理界面和线程安全事件队列，网络 I/O 完全在工作线程中。
- 下载先写入 `.part`，成功后原子改名；失败时清理临时文件，现有目标文件不覆盖。
- 无代理模式设置 `trust_env=False`，保证开关行为明确。

## 发生的问题与修复

1. 当前 PowerShell 的 `New-Item` 不支持 `-LiteralPath`：改用经过固定验证的绝对 `-Path`，目录成功建立。
2. Requests 网络异常继承 `OSError`：调整异常捕获顺序，先处理 `RequestException`，代理失效现在显示正确中文错误。
3. 当前命令输出编码为 CP1252：集成验证机器输出改用 ASCII，避免报告阶段误报失败。
4. 系统 tar 无法处理当前中文绝对路径：改用 .NET ZIP API 按相对路径写入并逐项核对归档。
5. WScript 快捷方式接口无法直接接受中文目标路径：改用 ASCII PowerShell 入口与 Base64 编码命令，最终快捷方式保持中文名称。
6. 用户反馈点击下载看起来无响应：补充即时状态反馈、兜底异常提示、直链限制说明和真实按钮集成测试。
