# Project002 第二版复盘

- 日期：2026-10-05
- 版本：2.0.0
- 状态：完成

## 结果

在原项目上增量加入 yt-dlp 页面解析、Deno JavaScript 运行时、FFmpeg/FFprobe、三种下载模式、结构化进度、取消进程树、代理、历史、错误翻译、安全更新和 PyInstaller onedir 交付版。第一版直接 MP4 能力未退化。

## 关键验证

- 24 项自动化测试全部通过。
- 分离 H.264/AAC 无重编码合并为 MP4。
- VP9/Vorbis 自动回退为 MKV，编码保持。
- Instagram 公开 Reel 实际下载成功。
- 下载中取消后进程树退出，临时文件可清理。
- 打包版随附四个独立工具并成功启动。

## 外部限制

当前网络出口访问 YouTube 时触发“登录以确认不是机器人”。按项目边界未加入 Cookie 或规避策略，因此用户给定 Shorts 在当前网络下不能下载；程序已准确提示需要登录。在线完整播放列表和真实 HTTPS 代理成功连接也因缺少可用外部条件未完成，已在验收矩阵明确标为部分验证。

## 本次经验

- 官方校验文件格式并不统一，必须按实际格式解析。
- yt-dlp 结构化结果中的 Unicode 路径仍应以文件系统扫描作为兜底。
- FFmpeg 清单和分片生成必须冻结同一工作目录。
- 无控制台 Windows 环境安装依赖时，应启用 UTF-8 并关闭富进度条。
