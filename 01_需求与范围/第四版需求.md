# 视频下载软件第四版需求

- 基线版本：现有 Windows 视频下载工具 v2.1
- 目标平台：Windows 客户端继续保留；新增 iPhone 原生 SwiftUI 客户端
- 服务端：Python、FastAPI、yt-dlp、FFmpeg
- 编译环境：GitHub Actions macOS Runner
- 安装方式：Windows 下载 IPA 后，通过 Sideloadly 使用免费 Apple 账号重签并安装

## 核心目标

1. iPhone 客户端输入视频 URL，查询视频信息和可用清晰度。
2. 云端服务完成下载、最高画质选择、音视频合并、进度管理、取消、重试和历史记录。
3. iPhone 下载服务端生成的文件，并保存到文件 App；系统兼容的视频可请求保存到相册。
4. 服务端必须有基本身份验证、任务隔离、并发限制、文件过期清理和滥用防护。
5. 不绕过 DRM、付费、会员、私密或平台访问控制。
6. GitHub Actions 生成可由 Windows 端 Sideloadly 后续重签名的 IPA，并上传为 Artifact。

## 范围边界

- 不把网页应用或 PWA 作为最终 iPhone 产品。
- 第一阶段不开发注册登录系统。
- 不把 Apple ID、密码或签名证书保存到代码仓库或 GitHub Actions。
- GitHub 产出的 IPA 不能视为已经具备可安装签名；必须经过 Sideloadly 重签。
- 免费 Apple 账号的设备安装和签名有效期受 Apple 当前规则限制。

## 基线确认

工作区中未发现独立第三版；用户已确认以 v2.1 作为第四版开发基线。
